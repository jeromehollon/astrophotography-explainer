Set up astro image tooling and agent guide for the explainer

The hackathon app (a static, desktop-only explainer of stacking and
calibration frames) needs web images and numbers taken from real FITS
and XISF data, and many agents will build it in parallel. This commit
adds that shared groundwork before any app code exists.

- tools/astro.py: one CLI (run via uv, in a project-local .venv) for
  FITS/XISF loading, lossless 8/16-bit PNG, JPEG/WebP export, and a
  PixInsight AutoSTF-equivalent stretch (median + -2.8*MADN shadows
  clip, MTF to a 0.25 target background). It also does star detection
  with elliptical Gaussian/Moffat FWHM fits and starlet (a trous
  B3-spline) wavelet denoising on chosen layers. The code is ours
  rather than an external tool's, so the page can explain exactly what
  each step computes.
- Using pypng for PNGs because Pillow cannot write 16-bit RGB.
- The FWHM guess iterates to the measured value. With a fixed 3 px
  guess, real 2800 mm subs (stars ~10 px wide) came back as ~1 px,
  because hot pixels were detected and the cutouts were too small.
- tools/test_astro.py checks the code against synthetic frames with
  known FWHM and noise, so later changes can't silently break the
  numbers the page shows.
- AGENTS.md (imported by CLAUDE.md) records the product requirements,
  the file/Figma ownership split for parallel agents, commit rules, and
  references. The .claude/skills/astro-image skill tells agents how to
  use the CLI.
- .gitignore excludes source_images/ (6.7 GB of local NGC 7331 data)
  and all FITS/XISF/raw formats.
